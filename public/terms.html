2. Nature of the Service

ShareDrop operates as a zero-signup, decentralized peer-to-peer communication platform:

  • Peer-to-Peer Architecture: In standard operation, files and text streams travel directly from browser to browser using WebRTC DataChannels encrypted via DTLS.
  • Zero Permanent Server Storage: Our signaling server only facilitates connection handshakes (SDP offers and ICE candidates). We do not operate cloud file lockers or preserve transferred user payloads.
  • Ephemeral Relay Fallback: Where network firewalls prohibit direct P2P connections, temporary encrypted relay chunks or ephemeral drops may pass through memory with an automatic 15-minute Time-To-Live (TTL).
