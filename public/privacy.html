Privacy Policy

Effective Date: November 9, 2026 · Version 1.0 · Zero-Knowledge Guarantee

Core Privacy Guarantee: ShareDrop does not store your files, does not read your clipboard or text beams, does not set advertising tracking cookies, and does not sell or share any user data with third parties. Your data travels directly between your devices.

1. The Zero-Retention Model

ShareDrop was engineered intentionally from day one to minimize data handling to the absolute technical minimum required for real-time signaling:

  • No User Accounts: You never create an account, log in, or provide personal identifiers (such as name, email, phone number, or password).
  • Zero Permanent File Storage: In WebRTC P2P transfers, files stream in 64 KB memory chunks directly from the sender's browser to the recipient's browser. No file data touches the server hard disk.
  • No Third-Party Analytics or Trackers: We do not load Google Analytics, Facebook Pixels, marketing scripts, or third-party fingerprinting services.

2. What Data Is Processed During Operation

To establish connections between devices, the following transient network data is processed strictly in memory:

  • IP Address Grouping: When you connect to /ws, your IP address is inspected to group devices sharing the same Wi-Fi / local subnet into a common discovery room. Local RFC1918 private IPs (192.168.x.x, 10.x.x.x) are collapsed into a local LAN pool. IP hashes are cleared upon disconnection.
  • WebRTC Signaling Handshakes: SDP (Session Description Protocol) offers, answers, and ICE candidates are relayed between peers sharing a room or pair secret. These contain only temporary network transport candidates and cryptographic fingerprints.
  • Persistent Pair Secrets: When you pair devices using a 6-digit code, a random 32-byte cryptographic secret is generated and saved strictly inside your browser's local localStorage. It is never logged in any permanent database.

3. Fallback Ephemeral Relay Transfers

When firewalls or strict symmetric NATs block direct WebRTC DataChannel connections, users may utilize the HTTP/CLI fallback drop API (/api/drop):

  • Relay files are saved in an ephemeral temporary directory with a strict 15-minute Time-To-Live (TTL).
  • Once downloaded or when the 15-minute window expires, the file is automatically purged from server disk via an unrecoverable sweep.
  • Files can be set to "burn after 1 download", deleting the payload immediately upon successful retrieval.

4. Local Storage & Cookies

ShareDrop does NOT use HTTP tracking cookies. We utilize standard browser localStorage solely for your convenience:

  • sharedrop_display_name: Saves your custom device nickname (e.g. "Sarthak's MacBook").
  • sharedrop_pair_secrets: Stores paired room secrets so your devices recognize each other automatically.
  • sharedrop_auto_accept_paired: Saves your preference for auto-accepting files from paired devices.

You can clear this data at any time through the in-app Settings modal or by clearing your browser site data.

5. International Compliance (GDPR, CCPA, DPDP)

Because ShareDrop does not store personal records, profiles, or file histories:

  • Right to Erase / Forget: All ephemeral data is erased automatically upon disconnection or 15-minute TTL.
  • Data Portability: No user data is held hostage or siloed.
  • No Data Sales: We do not sell, rent, or monetize user data in any manner.
