Frequently Asked Questions

Everything you need to know about peer-to-peer file transfer, encryption, pairing, and the terminal CLI.

Overview What is ShareDrop and how does it work?

ShareDrop is a secure, browser-based, peer-to-peer (P2P) file and text transfer platform inspired by Apple's AirDrop and open-source PairDrop. When you open ShareDrop on two devices connected to the same local Wi-Fi or router, they automatically discover each other via a lightweight WebSocket signaling server.

Once you click a peer and select files, the devices negotiate a direct WebRTC DataChannel. The file data is streamed straight from device to device across your local network without ever touching our servers or cloud storage.

Compatibility How does ShareDrop differ from Apple AirDrop?

While Apple AirDrop is locked strictly to Apple hardware (iOS and macOS) and relies on proprietary Bluetooth/Wi-Fi Direct protocols, ShareDrop is completely platform-agnostic:

  • Cross-Platform Freedom: Works seamlessly across iPhone, Android, Mac, Windows, Linux, Chromebook, and terminal CLIs.
  • Zero App Installation: Runs instantly inside any modern web browser (Chrome, Brave, Safari, Firefox, Edge).
  • Progressive Web App (PWA): Can be installed on your home screen or desktop dock for offline readiness and native Web Share Target integration.
  • No Accounts or Phone Numbers: Zero login, zero phone numbers, and zero tracking cookies required.
Security Is my data private? Can anyone inspect the files I send?

Your transfers are cryptographically private. Every WebRTC DataChannel connection enforces mandatory DTLS (Datagram Transport Layer Security) encryption with modern cipher suites (AES-128-GCM or AES-256-GCM).

Because the transfer is peer-to-peer:

  • Our servers never touch, view, or buffer your files or text beams.
  • The signaling server only exchanges SDP session parameters and ICE network candidate addresses.
  • Even if our signaling server were compromised, the adversary cannot decrypt the end-to-end DTLS payload.
Pairing Can I send files to someone on a different network or cellular data?

Yes! If devices are not on the same local Wi-Fi or behind carrier CGNAT firewalls, ShareDrop provides two simple pairing mechanisms:

  • 6-Digit Persistent Pairing Code: Click "Pair Devices" in the bottom dock, generate a 6-digit code or scan the QR code. The devices become paired peers indefinitely across any cellular, VPN, or public Wi-Fi network until manually unpaired.
  • Public Room: Click "Join Room" to create or join a short 5-character temporary room (e.g., DROP1) for spontaneous team transfers.
Performance Is there a file size limit?

There is no hard file size limit for peer-to-peer transfers. Whether you are sending a 2 MB photo or a 50 GB 4K video raw dump, ShareDrop handles it gracefully.

Our streaming engine utilizes a 64 KB chunking pipeline paired with backpressure flow control (bufferedAmountLowThreshold: 512 KB). This ensures your browser's RAM memory footprint stays constant and lightweight regardless of file size.

Developer How do I use the ShareDrop Terminal CLI?

ShareDrop ships with a first-class Node.js/Bun CLI for headless servers, developer laptops, and CI/CD pipelines:

# Send a file directly to paired browser or peer npx sharedrop-cli send ./build.tar.gz # Send an ephemeral HTTP drop with 15-minute TTL npx sharedrop-cli send ./backup.sql --ephemeral # Receive a drop using a 6-digit pair code npx sharedrop-cli receive 482910 --out ./downloads/

The CLI prints an ASCII QR code directly in your terminal for instant scanning with your mobile phone camera.

Open Source Is ShareDrop open source and can I self-host it?

Yes, 100%! ShareDrop is open source under the permissive MIT License. You can inspect the source code, contribute features, or deploy your own private instance inside your company intranet using Docker:

git clone https://github.com/sarvasva-dev/sharedrop-sarthakml.git cd sharedrop-sarthakml docker-compose up -d

View the full repository, architecture documentation, and deployment guides at github.com/sarvasva-dev/sharedrop-sarthakml.
